# 0903 회의준비

주제 : 로그가 차단된 환경에서 인프라 상태 변화(State Drift)를 기반으로 그래프를 통해 공격 경로를 역추적하는 프레임워크

[Boto3](https://app.notion.com/p/Boto3-3cfa6183e45080b58d31ead7e223e357?pvs=21)

시나리오1

stratus detonate aws.defense-evasion.cloudtrail-stop aws.credential-access.ec2-steal-instance-credentials

- cloudtrail 로그 중지 → ec2 인스턴스 탈취

1. 스텔스 데이터 유출

`stratus warmup aws.exfiltration.s3-backdoor-bucket-policy
stratus warmup aws.defense-evasion.cloudtrail-stop`

공격 전 스냅샷 

`stratus detonate aws.exfiltration.s3-backdoor-bucket-policy
stratus detonate aws.defense-evasion.cloudtrail-stop`

결과

```
MATCH p=(a:Attacker)-[action:MODIFIED|CREATED|DESTROYED]->(res:Resource)
OPTIONAL MATCH chain=(res)-[seq:PRECEDES]->(next_res:Resource)
RETURN p, chain
```
